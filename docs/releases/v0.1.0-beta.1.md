# VYBE v0.1.0-beta.1 — first public preview

Copy a YouTube video link and choose MP4 or MP3 through configurable desktop
shortcuts, or invoke the CLI directly. This is an early preview for review
and verification, not a claim of complete desktop validation.

## Included

- Python CLI: `run`, `download`, and `doctor`.
- Ctrl+Alt+V for MP4; Ctrl+Alt+A for MP3, both configurable.
- Single-video URL validation, one download at a time, output-file verification,
  cancellation, no-overwrite behavior, and application logs.
- ChatGPT/Codex skill, platform setup guides, issue forms, and a reproducible
  synthetic-media demo.
- Windows lock-contention handling and isolated platform mocks in listener tests.

## Installation

Download the source archive below and extract it, or clone the repository.
Use Python 3.10+ and install FFmpeg (including ffprobe) and Deno on PATH.
From the extracted source directory, follow `docs/INSTALL.md` to create a
virtual environment, install the package, and check your desktop permissions.
The Python package/CLI version is `0.1.0b1`.

## Verification limits

The synthetic test uses real yt-dlp/FFmpeg to transfer and decode MP4 and MP3
from a loopback fixture. It does not prove YouTube extraction, physical
shortcuts, clipboard access, or background/login startup. Consult the release
commit's GitHub Actions run for portable OS/Python results and
`docs/VERIFICATION.md` for the manual checks still needed.

Linux Wayland uses native desktop shortcuts invoking one-shot commands.
There are no standalone installers or bundled FFmpeg/Deno executables.
